# Книжный трекер — выбор коллекций

В treckere используется четыре коллекции, каждая по своему назначению. `list` хранит набор книг, который со временем меняется (книги добавляются), поэтому подходит изменяемый список. `tuple` задаёт фиксированную структуру одной записи `(id, title, author, year)` — поля книги не должны меняться после создания. `dict` позволяет мгновенно найти книгу по её идентификатору, что гораздо быстрее линейного перебора списка. `set` хранит только уникальные жанры, так как здесь важно отсутствие дублей, а не порядок или количество вхождений.
